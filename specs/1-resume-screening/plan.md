## Technical Context

### Stack Decisions

| Layer          | Choice                    | Rationale                                            |
| -------------- | ------------------------- | ---------------------------------------------------- |
| Frontend       | React + Next.js (App Router) | SSR 支持，中文生态丰富，企业级组件库成熟          |
| UI Framework   | Ant Design 5.x            | 完善的表格/表单/上传组件，中文场景最佳选择            |
| Backend        | Python + FastAPI          | AI 生态首选，原生 async，自动 OpenAPI 文档            |
| Database       | PostgreSQL 15+            | JSONB 支持半结构化简历数据，全文搜索，事务可靠        |
| Task Queue     | Celery + Redis            | Python 生态最成熟的异步任务方案，处理简历解析和AI分析  |
| AI/ML          | Claude API + OpenAI API   | 双通道确保可用性，Claude 中文理解优秀，结构化评分输出  |
| File Parsing   | PyMuPDF + python-docx + Tesseract | 组合方案覆盖 PDF/Word/图片全格式             |
| File Storage   | 本地文件系统（可扩展 S3） | 初期简单可靠，预留云存储接口                          |
| Authentication | JWT (bcrypt)              | 前后端分离标准方案，无状态易扩展                      |
| Deployment     | Docker Compose            | 一键部署全栈服务，开发生产环境一致                    |

### Architecture

```
┌─────────────────────────────────────────────────────────┐
│                     Frontend (Next.js)                   │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────────┐ │
│  │ 登录/注册 │ │ 岗位管理  │ │ 简历上传  │ │ 分析看板    │ │
│  └──────────┘ └──────────┘ └──────────┘ └────────────┘ │
└────────────────────────┬────────────────────────────────┘
                         │ REST API (JSON)
┌────────────────────────▼────────────────────────────────┐
│                   Backend (FastAPI)                      │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌────────────┐ │
│  │ Auth API  │ │ Job API  │ │Resume API│ │Analysis API│ │
│  └──────────┘ └──────────┘ └──────────┘ └────────────┘ │
│  ┌──────────┐ ┌──────────┐ ┌──────────┐                │
│  │Auth Svc  │ │Parser Svc│ │  AI Svc  │                │
│  └──────────┘ └──────────┘ └──────────┘                │
└──────────┬──────────────┬──────────────┬───────────────┘
           │              │              │
    ┌──────▼──────┐ ┌─────▼──────┐ ┌────▼────────┐
    │ PostgreSQL  │ │   Redis    │ │  File Store │
    │  (数据存储)  │ │ (队列/缓存) │ │ (简历文件)   │
    └─────────────┘ └─────┬──────┘ └─────────────┘
                          │
                   ┌──────▼──────┐
                   │   Celery    │
                   │   Workers   │
                   │ (解析+分析)  │
                   └─────────────┘
```

**关键架构决策**:
- **前后端分离**: Next.js 前端通过 REST API 与 FastAPI 后端通信
- **异步任务**: 简历解析和 AI 分析通过 Celery 异步执行，前端通过轮询获取进度
- **多租户**: 通过 company_id 实现数据隔离，所有查询自动附加公司范围
- **双 AI 通道**: 主用 Claude API，失败自动降级到 OpenAI API

### Key Integrations

| Integration       | Purpose                    | Method              |
| ----------------- | -------------------------- | -------------------- |
| Claude API        | 简历智能分析评分            | REST API (Anthropic SDK) |
| OpenAI API        | 备用分析通道                | REST API (OpenAI SDK) |
| PyMuPDF           | PDF 文件文本提取            | Python Library       |
| python-docx       | Word 文件解析              | Python Library       |
| Tesseract OCR     | 图片简历文字识别            | Python Library       |

## Constitution Check

本系统为全新项目，无既有 constitution 约束。关键设计原则：

- **安全优先**: 密码 bcrypt 加密，JWT Token 认证，公司级数据隔离
- **隐私合规**: 简历数据加密存储，权限最小化原则
- **异步优先**: 耗时操作（解析、AI 分析）全部异步处理
- **可扩展**: 预留 S3 存储接口、双 AI 通道降级、Docker 部署
